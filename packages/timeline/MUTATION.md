Each `tool/mutants/<source>.txt` starts with a `tests:` line naming the test files run for its mutants: every file that uses the source directly, through a source that imports it, or through `test/support.dart`. Rerun a source's mutants whenever any test on its `tests:` line changes.

The survivors:

- `lib/src/clock.dart` `inClockRange` (in `reminder.dart` `_quietStart` before slice 7 round 3): `to < from` → `to <= from` (a range that starts and ends at the same time treated as wrapping midnight). Differs only when a range's from equals its to, which the validator's `emptyRange` check rejects for quiet hours and bookable hours; `fixtures/invalid/empty-quiet-hours-umms` and `fixtures/invalid/empty-bookable-hours-umms` prove it.
- `lib/src/past_due.dart` `pastDueOf`: `discharge: null` → `discharge: appointment`. Discharge-anchored steps return before the effect is computed, and `effectOf` reads only the step's own anchor, so the discharge value is never read.
- `lib/src/past_due.dart` `pastDueOf`: `effectOf(step.anchor, …)` → `effectOf(Anchor.appointment, …)` (every step counted from the appointment). Arrival is set to the appointment, so an arrival step's anchor is the same instant either way, and discharge steps never get here.
- `lib/src/selection.dart` `decodeQr`: `.where(ticked.contains)` → `.where(code.ticked.contains)` (group count taken from the code's list instead of the set). Equivalent: a duplicate ID is rejected earlier in the same function, so the list and the set hold the same IDs.
- `lib/src/selection.dart` `_module` and its three callers, 4 mutants: unreachable by construction: fail-closed guard. The mutants are "decodeQr: a missing module is a null-check crash", "a missing base module is a null-check crash", "a missing optional module is a null-check crash" and "the missing module not named". `verifyBundle` refuses a bundle without every module the manifest lists, and `Bundle` has only its private constructor and an unmodifiable module map, so no `Bundle` can lack one. The guard stays so a lookup fails closed instead of crashing.
- `lib/src/publish.dart` `stopsDrinking`: `every` → `any` ("one parameter choice with npo counted for every choice"). Unreachable with valid content: a parameter range starts at 1 or more (`parseModule` rejects less since slice 7b), and "before" fixes the sign of the day, so every choice of a parameter puts an npo day step on the same side of the appointment. A range whose min exceeds its max, which would give no choices at all, is rejected by `parseModule` since slice 7c, so no content that parses can tell the two apart. Test 45b pins the valid case.
- `lib/src/selection.dart` `_utc`: the `$` end anchor dropped. Equivalent: `DateTime.parse` rejects any text after the `Z` (tried: trailing letters, a space, a newline, an offset, a digit, a second `Z`), so the code is still rejected with a FormatException.
